# Power BI Sales & Returns Dashboard

An interactive Power BI dashboard designed to analyze sales performance, profitability, orders, returns, customers, regions, categories, and segments.

## Dashboard Pages

### 1. Executive Sales Dashboard
- Total Sales
- Total Profit
- Total Orders
- Profit Margin
- Sales by Category
- Profit by Category
- Sales by Region
- Sales by Segment

### 2. Returns & Customer Analysis
- Return Rate
- Returned Orders
- Returned Orders by Region
- Returned Orders by Category
- Returned Orders by Segment

## Tools Used

- Microsoft Power BI
- DAX
- Data Modeling
- Data Visualization
